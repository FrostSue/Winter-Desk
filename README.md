# WinterDesk

WinterDesk is an open-source, lightweight ambient desktop companion for Windows 10 and Windows 11. It brings interactive holiday atmosphere, dynamic snowfall physics, custom taskbar companions, and decorations to your desktop.

## Highlights

- Smooth GPU-accelerated snow particle simulation at 60 FPS
- Surface accumulation engine that lets snow gather naturally on the Windows Taskbar and active application windows
- Interactive snowman builder and customization system on the taskbar
- Snowman snowball duels and friendly interactions
- Animated taskbar vehicles including snowploughs and holiday express trains
- Draggable and customizable festive decorations
- Modern Windows system tray control panel with weather and density adjustments
- Click-through transparent overlay ensuring zero disruption to everyday workflows

## Architecture

The project is built using:
- **Electron**: System tray management, transparent desktop overlay window, and native Windows integration
- **Vite & TypeScript**: Modern fast development environment and type-safe codebase
- **PixiJS & HTML5 Canvas**: High-performance particle rendering and 2D physics

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run in development mode:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
